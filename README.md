# FUTURE_UX_02 – Local Services Clinic App

## 📌 Overview
A UI/UX design for a **Local Services Clinic App**, designed to help users easily discover clinic
services and access important information through a simple and user-friendly interface.

## 🎨 Design Tool
- Figma

## ✨ Key Features
- Clinic and service information
- Easy navigation
- Appointment-related interface
- Clean and user-friendly design
- Simple service discovery
